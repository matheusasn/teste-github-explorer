## Objetivo do dia

Telas reais funcionando, polish, README de entrega. Vault rodando desde ontem — hoje as decisões emergem da camada de UI/UX, não da arquitetura base.

## O que aconteceu

### Manhã — Blocos 5, 6, 7, 8

Abri o vault, reli o briefing pra confirmar o que ainda falta (busca + detalhe + issues + paginação + erros + tema).

- **Bloco 5 — Navigation:** `@react-navigation/native-stack` + `@react-navigation/native` + `react-native-safe-area-context` + `react-native-screens`. `RootNavigator` inicial com Showcase como tela de DS pra validar tokens.
- **Bloco 6 — Search:** TanStack Query setup, `useSearchRepos` com debounce 300ms + `useInfiniteQuery`. `SearchScreen` + `SearchBar` + `RepoCard` + `RepoList` cobrindo todos os estados (skeleton, empty, error com retry, infinite scroll, pull-to-refresh).
- **Bloco 7 — RepoDetail:** `useRepoDetails` + `RepoDetailScreen` com avatar grande, descrição, 3 stat cards, botão "Ver issues abertas".
- **Bloco 8 — Issues:** `useRepoIssues` + `IssuesScreen` + `IssueItem` com `formatRelativeDate` em PT-BR inline (sem dep externa — escopo não justifica `date-fns`).

### Tarde — feedback loop

Primeiras renderizações no simulador trouxeram dois feedbacks que precisaram virar refactor antes de seguir:

- **Cards de tamanhos diferentes** atrapalhavam ritmo visual da lista — `RepoCard` ganhou `minHeight: 40` reservando 2 linhas pra descrição + fallback "Sem descrição" quando vier vazio.
- **"Estrutura tá com cara de IA"** — autoavaliação crítica olhando o código gerado. Sinais detectados (cruzando com [[00-contexto/meu-perfil-tecnico|perfil técnico]]): JSDocs longos descrevendo o que o código já dizia, `Button` com switch+helper quando objeto literal serve, hook `useColors()` redundante. Limpeza geral aplicada.

Isso virou rejeitado novo no vault: [[03-rejeitado/jsdoc-longo-sobre-codigo]] — comentário existe pra carregar o porquê não-óbvio, não pra narrar o código.

Padrão de commits adotado: Gitmoji + Conventional, em PT-BR, validado via Husky + Commitlint custom parser. ADR 009 registrada.

### Tarde-noite — Bloco 9 (Tab bar + Settings)

`@react-navigation/bottom-tabs` com 3 tabs (Search, Settings, e Profile a definir). 3 modos de tema (system/light/dark), `SettingsScreen` estilo iOS, `AppearanceScreen` com checkmark no modo ativo.

Mudança visual no tema dark: background para `#000000` puro (estilo GitHub Mobile) em vez do `#0d1117` do site web. Decisão estética alinhada ao público alvo (desenvolvedores acostumados ao app mobile).

Feedback que mudou rumo: **"tab Perfil sem login faz sentido?"**. Sem token, a tab ficaria como fachada sem função. Decisão: tornar condicional ao `EXPO_PUBLIC_GITHUB_TOKEN`. Formalizei como ADR 010 — autenticidade > completude visual.

### Noite — Bloco 10 + revisão final

**Bloco 10 — Perfil autenticado.** `UnauthorizedError` adicionado à discriminated union do domain. Nova entidade `User`, método `getAuthenticatedUser` no Repository, `GetAuthenticatedUserUseCase`, hook `useAuthenticatedUser`, `ProfileScreen` com avatar / bio / 3 stats / botão "Abrir no GitHub".

Tab `ProfileTab` registrada condicionalmente no `RootNavigator` com base no token.

Configuração: `.env` + `.env.example` + `.gitignore` ajustado pra incluir `.env`. Rate limit apareceu durante teste sem token — token resolveu de imediato e ainda abriu porta pra autenticação real.

Outra decisão emergiu durante refactor da `GitHubRepositoryImpl`: o helper `apiGet` ficou enxuto, sem família completa (`apiPost`, `apiPatch` etc.). Formalizei como ADR 011 — app é read-only, YAGNI vence DRY especulativo.

Rejeitado capturado durante decisão de cache: [[03-rejeitado/persistencia-offline]] — `PersistQueryClient` + storage driver não está no PDF, stale-while-revalidate em memória atende.

**README final** em 5 seções (stack, como rodar, arquitetura, uso de IA, faria diferente).

Durante a passagem final pelo vault, **avaliação crítica da cor primary** ([[01-decisoes/2026-05-21-AVALIACAO-CRITICA-cor-primary|⚠️]]). Ao revisar tokens vs uso real nos botões, percebi que primary verde está usada com semântica de info (mais coerente com azul). Documentei como "decisão ruim identificada, fix pendente" em vez de mascarar.
